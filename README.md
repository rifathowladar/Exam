# NSDA Exam Project Prompt

আমার জন্য একটি **NSDA Practical Exam উপযোগী Website Project** তৈরি করো।

## Technology

শুধুমাত্র ব্যবহার করবে:

* HTML5
* CSS3
* Bootstrap 5

কোনো JavaScript, React, Tailwind CSS, jQuery বা অন্য কোনো Framework ব্যবহার করবে না।

## Project Requirements

Website হবে **simple, clean, professional এবং fully responsive**।

শুধুমাত্র প্রয়োজনীয় Section তৈরি করবে:

* Navbar
* Hero Section
* About Section
* Services / Products Section
* Gallery / Featured Section
* Contact Section
* Footer

## NSDA Exam Coding Rules

* Code যতটা সম্ভব **কম এবং সহজ** রাখবে।
* Bootstrap 5-এর built-in classes সর্বোচ্চ ব্যবহার করবে।
* Custom CSS যতটা সম্ভব কম লিখবে।
* অপ্রয়োজনীয় Custom Class তৈরি করবে না।
* একই কাজের জন্য আলাদা CSS class তৈরি করবে না।
* Bootstrap Grid System ব্যবহার করবে।
* `container`, `row`, `col-md`, `col-lg` ব্যবহার করবে।
* Bootstrap Utility Classes ব্যবহার করবে।
* Website অবশ্যই Mobile, Tablet এবং Desktop Responsive হবে।
* Advanced CSS বা Complex Code ব্যবহার করবে না।
* Code এমন হবে যেন NSDA Practical Exam-এ সহজে লেখা ও ব্যাখ্যা করা যায়।
* প্রতিটি Section-এর structure সহজ রাখবে।
* Code দেখে যেন একজন Examiner সহজেই বুঝতে পারেন।


Bootstrap 5 CDN ব্যবহার করবে।

## Important

প্রজেক্টটি এমনভাবে তৈরি করবে যাতে NSDA Practical Exam-এর সময় দ্রুত সম্পন্ন করা যায় এবং Viva-তে সহজে প্রতিটি Code ব্যাখ্যা করা যায়।

**প্রথমে Project-এর নাম দেবে। তারপর সম্পূর্ণ `index.html` এবং `style.css` Code দেবে। শেষে সংক্ষিপ্তভাবে প্রতিটি Section-এর কাজ ব্যাখ্যা করবে।**
